# @yu-iskw/xbot-slack

Slack bot for xbot, built on Mastra Channels and `@chat-adapter/slack`. It includes a user allowlist and a per-user daily quota, and the process serves only the Slack webhook route.

```bash
SLACK_BOT_TOKEN=... SLACK_SIGNING_SECRET=... XBOT_MODEL=<provider>/<model-id> npx @yu-iskw/xbot-slack
```

See [docs/api](https://github.com/yu-iskw/xbot/blob/main/docs/api/README.md).
