# @yu-iskw/xbot-cli

The `xbot` command: an interactive research REPL plus one-shot commands, running the xbot agent in-process.

```bash
npx @yu-iskw/xbot-cli research "What are developers discussing about Mastra?" --mock
xbot chat           # needs XBOT_MODEL
xbot history list
xbot doctor
```

See the [quickstart](https://github.com/yu-iskw/xbot/blob/main/docs/quickstart/README.md).
