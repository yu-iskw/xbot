# @yu-iskw/xbot-http

Authenticated REST API with SSE chat streaming for xbot, built on Hono and Mastra.

```bash
XBOT_HTTP_TOKENS="<token>:default" npx @yu-iskw/xbot-http
```

Or embed it: `createXbotHttpApp({ runtime, tokens })`. Endpoints are listed in [docs/api](https://github.com/yu-iskw/xbot/blob/main/docs/api/README.md).
