# @yu-iskw/xbot-mcp

MCP server for xbot over stdio or authenticated Streamable HTTP. It has six tools (`xbot_search_posts`, `xbot_get_post`, `xbot_research`, `xbot_discover_topics`, `xbot_get_report`, `xbot_search_history`) and exposes reports as resources.

```bash
npx @yu-iskw/xbot-mcp --mock
```

See [docs/api](https://github.com/yu-iskw/xbot/blob/main/docs/api/README.md).
